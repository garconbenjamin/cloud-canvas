# CloudCanvas

CloudCanvas 是以 React 與 Cloudflare 平台打造的多人協作畫布，使用 D1 保存畫布資料、R2 儲存圖片，並支援 Google OAuth 與即時同步。

## 專案進度檢查表

完成每項功能並通過下方驗收條件後，再勾選對應項目。

- [ ] **1. Public Repository 與 Cloudflare 部署**
  - 建立可公開存取的程式碼 Repository。
  - React App 已部署至 Cloudflare。
  - 公開網址可正常開啟並顯示應用程式。

- [ ] **2. 基本畫布編輯功能**
  - 可新增矩形節點與文字節點。
  - 可使用滑鼠選取節點。
  - 可使用滑鼠拖曳並移動節點。

- [ ] **3. D1 資料持久化**
  - 新增或修改的節點會寫入 Cloudflare D1。
  - 重新整理瀏覽器後，畫布內容與節點位置維持不變。

- [ ] **4. 多人即時協作**
  - 兩個瀏覽器視窗可開啟同一個畫布。
  - A 視窗拖曳節點時，B 視窗可即時看到節點移動。
  - 加分項目：畫布可顯示其他使用者的即時游標位置。

- [ ] **5. Google OAuth 與建立者資訊**
  - 可透過 Google OAuth 登入。
  - 畫面會顯示目前登入者的名稱或頭像。
  - 每個節點會記錄並顯示建立者資訊。

- [ ] **6. R2 圖片上傳與持久化**
  - 可將圖片拖曳至畫布進行上傳。
  - 圖片檔案會儲存至 Cloudflare R2。
  - 上傳完成後，圖片會顯示在畫布中。
  - 重新整理瀏覽器後，圖片仍可正常顯示。
